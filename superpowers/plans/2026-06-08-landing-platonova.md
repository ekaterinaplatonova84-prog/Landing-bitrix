> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Собрать продающий лендинг на Tilda для бизнес-аналитика и интегратора Битрикс24 Екатерины Платоновой.

**Architecture:** Одностраничный лендинг из 9 блоков на Tilda. Каждый блок собирается через Zero Block или готовые блоки Tilda. Форма заявки подключается к Telegram или email через встроенные интеграции Tilda.

**Tech Stack:** Tilda Publishing (tilda.cc), встроенные блоки + Zero Block для кастомных секций, Tilda Forms для формы заявки.
